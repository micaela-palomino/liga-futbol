¿Cómo funciona el Algoritmo Dijkstra?

El algoritmo de Dijkstra funciona de la siguiente manera:

  1. Inicialización: Establece la distancia del nodo origen como 0
  2. Selección: Elige el nodo no visitado con menor distancia
  3. Actualización: Calcula distancias a nodos vecinos
  4. Repetición: Continúa hasta encontrar el destino
Ventajas: Garantiza encontrar la ruta más corta
Aplicaciones: GPS, redes, planificación de rutas
