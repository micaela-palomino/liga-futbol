🌳 Minimum Spanning Tree (MST) ⚽

🔗 Como conectar todos los estadios con el menor costo total de construcción de carreteras. Encuentra la red mínima que une todos los puntos sin ciclos, como el sistema de transporte más eficiente para conectar todas las sedes. 🌳 ¡Optimización de infraestructura! 🛣️

🔧 Configuración del MST
Mantén Ctrl presionado para seleccionar múltiples estadios
📚 Algoritmos MST
🏗️ Algoritmo de Kruskal:

Ordena todas las aristas por peso y las agrega si no forman ciclos. Usa Union-Find para detectar ciclos.

Complejidad: O(E log E)
🌱 Algoritmo de Prim:

Crece el árbol desde un nodo inicial, siempre agregando la arista de menor peso que conecte un nuevo nodo.

Complejidad: O(E log V)
🔄 Algoritmo de Borůvka:

En cada iteración, cada componente conectada encuentra su arista de menor peso y la agrega.

Complejidad: O(E log V)
