¿Cómo funciona el Algoritmo Backtracking?

El algoritmo de Backtracking funciona de la siguiente manera:

  1. Exploración: Intenta construir una solución paso a paso
  2. Validación: En cada paso, verifica si la solución parcial es válida
  3. Avance: Si es válida, continúa al siguiente paso
  4. Retroceso: Si no es válida o llega a un callejón sin salida, retrocede
  5. Completación: Encuentra todas las soluciones posibles
Advertencia: El tiempo de ejecución crece exponencialmente
Ventaja: Encuentra todas las soluciones válidas
Complejidad

Tiempo: O(b^d) donde b es el factor de ramificación y d la profundidad
Espacio: O(d) para almacenar la pila de recursión
